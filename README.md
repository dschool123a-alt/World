# WorldMorph

WorldMorph is a server-side Minecraft 26.3 Fabric mod focused on an emergent civilization simulation.

## First test

The first milestone verifies that the mod loads on the server and registers a command.

Run:

    /worldmorph test

Expected result:

    WorldMorph test OK - server-side core is running.

## Target

- Minecraft 26.3
- Fabric Loader 0.19.5
- Fabric API 0.161.0+26.3
- Java 25
- Fabric Loom 1.17.21
